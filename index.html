ats-strike

github.com/gcontini/ats-strike ↗

My AI lab turned product for my friends: it reads a job description and your raw experience, then writes a tailored, two-page PDF CV and cover letter using any OpenAI-compatible model.

Each reply is re-validated against a schema and reviewed against your profile, so the output stays honest, ATS-friendly and well formatted.

A stateless FastAPI server keeps the model keys and a sandboxed pdflatex toolchain, while a single-file client watches your clipboard waiting for the Job Description; no Python needed to run it.

github.com/open-license-manager/licensecc ↗

My longest-running open-source project: a cross-platform C++ library for software licensing and copy protection that binds a binary to specific hardware and blocks use in virtualized environments.
